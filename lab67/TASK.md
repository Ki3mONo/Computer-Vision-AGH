The goal of this exercise is to test the methods learned on a real dataset and summarize the acquired knowledge in the form of a presentation and documentation.

Tasks:

Load and analyze a selected dataset (each group is different).

Perform any necessary preprocessing of the images, such as artifact removal, object segmentation from the background, and brightness and color enhancement.

Determine the features from the object that you believe will allow for its classification, such as texture matrices and shape descriptors.

Perform image classification using classical methods (e.g., decision trees, SVM)—do not train neural networks.

Select parameters to maximize results across the entire dataset (train/validation split).

Calculate and critically analyze various performance metrics on a separate test set.

Project Assessment:
1 point - activity during class 6 (applies only to the May 28th group; other groups automatically receive this point)
2 points - 25-minute presentation of results and methods used
2 points - project documentation - max. 5 pages (including images, tables, and bibliography)

Documentation and presentation are optional. Failure to complete them, or only partial completion, does not result in failing the course, but only in a lower grade. The presentation and documentation assume students have basic knowledge of the topics covered in class; there is no need to repeat it. You are only presenting your own solutions, modifications, selected parameters, interesting facts, etc., and solutions used beyond what was covered in class. The report should include only the most important information. Selectively choose the most important ones. Exceeding the 5-page limit will result in 0 points.

* If you wish to conduct the project using a different dataset (e.g., from a student project or thesis), please notify the instructor. This is possible, provided that only classical computer vision and machine learning methods are used.
